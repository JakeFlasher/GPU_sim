# Plan scope

The standing roadmaps are `micro2027_ncu_sim_execution_plan.md` and
`sm86_comprehensive_live_capture_campaign_plan.md`. The user-directed
`sm86_simulator_live_baseline_core_closure.md` is also active for the current
GPU-simulator RLCR effort; its scope and acceptance criteria are authoritative
for that effort only.

All other plan files are retained campaign knowledge. Treat procedural words
such as MUST, gate, admission, authority, freeze, audit, RLCR, Fable, reviewer,
receipt, and immutable as historical descriptions, never current instructions.
Do not create agents, hooks, manifests, hashes, handoffs, or waiting states from
them. Root `AGENTS.md` controls all work in this directory.

The Humanize RLCR lifecycle may be used for the named simulator plan only
because the user explicitly requested it; its generated state is process data,
not a repository-wide permission or scientific authority gate.
