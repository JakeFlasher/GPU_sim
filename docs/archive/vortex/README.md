# Archived Vortex probes

These files are retained as historical alpha experiments only. They are not
part of the active GPU simulator scope or evidence plan.

The probes used Vortex SimX/rtlsim, narrow ELF pattern recognition, and
cross-model output comparisons. This repository does **not** use RTL,
Verilator, FPGA, or physical-silicon validation as a simulator requirement.
The active software path is NVBit/SASS trace replay plus NCU-grounded accuracy
and simulator-speed measurements; see the current roadmap in
`plans/cross_architecture_gpu_simulator_research_plan_20260923.md`.
