# [1. Using Inline PTX Assembly in CUDA](https://docs.nvidia.com/cuda/inline-ptx-assembly#using-inline-ptx-assembly-in-cuda)[](https://docs.nvidia.com/cuda/inline-ptx-assembly/#using-inline-ptx-assembly-in-cuda "Permalink to this headline")

The NVIDIA<sup>®</sup> CUDA<sup>®</sup> programming environment provides a parallel thread execution (PTX) instruction set architecture (ISA) for using the GPU as a data-parallel computing device. For more information on the PTX ISA, refer to the latest version of the [PTX ISA reference document](https://docs.nvidia.com/cuda/parallel-thread-execution/index.html).

This application note describes how to inline PTX assembly language statements into CUDA code.
