# [1. Introduction](https://docs.nvidia.com/cuda/parallel-thread-execution#introduction)[](https://docs.nvidia.com/cuda/parallel-thread-execution/#introduction "Permalink to this headline")

This document describes PTX, a low-level _parallel thread execution_ virtual machine and instruction
set architecture (ISA). PTX exposes the GPU as a data-parallel computing _device_.
