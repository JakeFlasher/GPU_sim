## [13.14. Changes in PTX ISA Version 7.7](https://docs.nvidia.com/cuda/parallel-thread-execution#changes-in-ptx-isa-version-7-7)[](https://docs.nvidia.com/cuda/parallel-thread-execution/#changes-in-ptx-isa-version-7-7 "Permalink to this headline")

**New Features**

PTX ISA version 7.7 introduces the following new features:

- Extends `isspacep` and `cvta` instructions to include the `.param` state space for kernel
function parameters.

**Semantic Changes and Clarifications**

None.
