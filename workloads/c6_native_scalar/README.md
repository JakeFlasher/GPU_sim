# C6 native scalar continuation probe

Hand-authored SM86 cubin with one memory-free warp and a short scalar suffix.
It is a real NVBit/SASS input for typed-boundary inspection, not a synthetic
reference example. It has no result buffer: host correctness is launch and
completion only. A complete typed state or positive native continuation must
still be demonstrated independently; the probe does not assume that absence
of memory is sufficient.
