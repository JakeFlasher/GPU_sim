# Label-tool scope

The direct NCU entry point is `collect_ncu.py`; `metrics.py` and `ncu_csv.py`
provide small reusable parsers. Superseded M5/M6 authority, receipt, audit,
provenance, hash, and validation workflow files have been removed and must not
be recreated under another name. Root `AGENTS.md` controls; NCU collection is
an ordinary experiment and never requires a workflow artifact or approval.
