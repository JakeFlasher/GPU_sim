# Evaluation scope

`direct_score.py` is the ordinary evaluator. `profile.py` is a plain optional
Linux `perf` wrapper. The `contracts/`, `guards/`, `production_*`, `score.py`,
and `bench.py` surfaces are retained historical campaign compatibility code.
Do not treat their authority, receipt, seal, admission, hash, clean-tree, or
production-disable states as permission requirements for simulator work.

Use those compatibility modules only when the user explicitly selects the
SOL/campaign stack through `run-sol-campaign`. Root `AGENTS.md` controls.
